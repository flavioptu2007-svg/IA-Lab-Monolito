# Apresentações profissionais para educação

Crie uma narrativa com pergunta inicial, desenvolvimento e síntese aplicável.
Produza exatamente a quantidade slide_count solicitada.
Uma ideia principal por slide; títulos específicos e texto enxuto. Use de 3 a 20
slides, com até quatro tópicos por slide. Alterne capa, conteúdo, comparação e
fechamento quando fizer sentido. Formato 16:9; tipografia legível e alto contraste.
Cada tópico ou referência deve ter até 110 caracteres.
Detalhes, exemplos e orientações de fala ficam nas notas do apresentador.
Inclua uma pergunta de discussão ou verificação da aprendizagem. Não invente
imagens, fontes, citações, dados ou pesquisas. Use somente referências recebidas;
quando ausentes, deixe sources vazio para revisão pelo professor.
A saída deve ser o objeto JSON do schema recebido, sem metadados de aprovação.
